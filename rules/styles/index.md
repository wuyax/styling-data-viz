## 风格选择与路由机制 (Routing Logic)

根据用户 Prompt 的关键词自动识别并匹配对应风格：

1. **若包含以下关键词** ➔ 自动选用 `huanzi`（幻紫赛博霓虹风格）：
   - “幻紫”、“赛博”、“霓虹”、“粉紫”、“算力中心”、“元宇宙”、“AI”、“科幻”、“机甲”等。
   - 使用主题：`references/themes/huanzi-theme.json`

2. **若包含以下关键词** ➔ 自动选用 `guofeng`（国风水墨风格）：
   - “国风”、“水墨”、“中式”、“生态环境”、“绿色”、“文化”、“青绿山水”、“古风”、“宋韵”等。
   - 使用主题：`references/themes/guofeng-theme.json`

3. **若包含以下关键词或未指定风格** ➔ 默认选用 `qunqing`（群青科技风格）：
   - “科技感”、“驾驶舱”、“暗色”、“极客”、“IT/数据中心”、“监控”、“通用”等。
   - 使用主题：`references/themes/qunqing-theme.json`
